# Frontend shared components

Phase 4 establishes this directory as the canonical owner for reusable public UI markup.

## Modules

- `core.js` — HTML escaping, shared SVG icons and class composition
- `brand.js` — RC IT Services brand lock-up
- `buttons.js` — button/link class and markup primitives
- `navigation.js` — utility bar, desktop navigation, mega menus and mobile navigation
- `footer.js` — corporate footer and legal links
- `layout.js` — responsive containers and section wrappers
- `content.js` — breadcrumbs, page heroes, section headings and CTA panels
- `cards.js` — reusable action, capability, industry, product, topic, help and delivery cards
- `forms.js` — accessible field, select, textarea, consent and form-action markup
- `feedback.js` — dialog, status and toast markup primitives
- `index.js` — public component exports

Shared components must remain presentation-focused. Route decisions, API calls and business data remain outside this directory.
